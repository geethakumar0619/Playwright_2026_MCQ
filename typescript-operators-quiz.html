Cheat sheet — pre vs post increment 
let x = 5;
let a = x++;   // a = 5, x = 6   (use first, then add)
let b = ++x;   // b = 7, x = 7   (add first, then use)

let y = 5;
let c = y--;   // c = 5, y = 4   (use first, then subtract)
let d = --y;   // d = 3, y = 3   (subtract first, then use)

The variable always ends up changed by 1. What differs is the value the expression hands back — the old value for the post form, the new value for the pre form.
