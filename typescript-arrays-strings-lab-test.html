How this works

  • Keep the given function name and parameter order — the grader calls it by name.
  • Return the answer; don't just console.log it. The only exception is assignment 11, which is graded on what it prints.
  • Use the method the assignment names (e.g. push() for assignment 1). Each card includes a code check for it, counted as one of its test cases.
  • Some assignments also check that you didn't modify the input array — concat, slice and map return new arrays.
  • Strings are compared exactly — case and spaces matter.
  • TypeScript annotations are fine — they're stripped before running. Plain JavaScript works too.
  • Infinite loops are caught by a guard and reported as a failed test, so a runaway loop won't freeze the page.
  • Your code is saved in this browser as you type, so a refresh won't lose it.
  • Tick Practice mode to check one assignment at a time instead of waiting for the final submit.
