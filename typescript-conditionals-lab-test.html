How this works

  • Keep the given function name and parameter order — the grader calls it by name.
  • Return the answer; don't console.log it. A logged value scores zero.
  • TypeScript annotations are fine — they're stripped before running. Plain JavaScript works too.
  • String answers are compared case-insensitively and trimmed, so "Winter" and "winter" both pass.
  • Your code is saved in this browser as you type, so a refresh won't lose it.
  • Avoid loops — none of these need one, and an accidental infinite loop will freeze the page.
  • Tick Practice mode to check one assignment at a time instead of waiting for the final submit.
