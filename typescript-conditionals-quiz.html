Cheat sheet — which conditional to use
FormUse whenShape
ifOne optional actionif (c) { }
if-elseExactly two outcomesif (c) { } else { }
if-else-ifSeveral conditions, or rangesif (c1) { } else if (c2) { } else { }
switch-caseOne value against many fixed valuesswitch (x) { case 1: … break; default: … }
? :Two outcomes that produce a valuec ? a : b

Rule of thumb: discrete values → switch, ranges → if-else-if. A switch cannot test marks >= 90, because each case is an equality check against one value.

Cheat sheet — the three switch rules people forget
RuleWhat happens without it
breakFall-through — execution continues into the next case's code, so several blocks run
defaultNothing runs when no case matches — no error, just silence
=== matchingCases are matched with strict equality, so "3" never matches case 3
