Cheat sheet — the three forms side by side
TypeExampleKey features
Namedfunction sum(a: number, b: number): number { return a + b; }Has a name, reusable, traditional syntax, hoisted
Anonymouslet multiply = function(x: number, y: number): number { return x * y; };No name, stored in a variable, not hoisted
Arrowlet square = (x: number): number => x * x;Shortest syntax, uses =>, implicit return on one line, lexical this

All three take typed parameters the same way (name: type) and declare a return type the same way (): type after the parameter list).

Cheat sheet — arrow function bodies 
// One line — no braces, no return. The expression IS the result.
let square = (num: number): number => num * num;

// Multi-line — braces require an explicit return.
let greet = (name: string): string => {
  return `Hello, ${name}!`;
};

// The trap: braces WITHOUT return. Returns undefined.
let broken = (num: number): number => { num * num; };

The moment you add { }, you are writing a statement block — and a block gives nothing back unless you say return.
