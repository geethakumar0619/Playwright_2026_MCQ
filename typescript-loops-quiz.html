Cheat sheet — which loop to use
LoopCondition checkedMinimum runsUse when
whileBefore each pass0You don't know the count; may not need to run at all
do-whileAfter each pass1The body must run at least once (menus, prompts)
forBefore each pass0The number of iterations is known up front

The one-line rule: known count → for; unknown count → while; unknown count but must run once → do-while.

Cheat sheet — break vs continue
breakcontinue
EffectExits the loop entirelySkips the rest of this pass only
Later iterationsNever happenStill happen
In nested loopsExits the inner loop onlyContinues the inner loop only
Danger—In a while, it can skip your increment → infinite loop
// break — stops at 5
for (let n = 1; n <= 10; n++) {
  if (n === 5) { break; }
  console.log(n);          // 1 2 3 4
}

// continue — skips only 3
for (let m = 1; m <= 5; m++) {
  if (m === 3) { continue; }
  console.log(m);          // 1 2 4 5
}
