# Getting Started with TypeScript — MCQ Quiz Pack

30 multiple-choice questions covering Introduction to TypeScript, Setup, and the First Program,
with answer key and explanations.

## Files

| File | Best for |
|------|----------|
| `TypeScript_Basics_MCQ_Interactive.html` | **Self-study.** Open in any browser, click an option to get instant right/wrong feedback + explanation, live score at the top. Works offline; no internet needed. |
| `TypeScript_Basics_MCQ_Printable.html` | **Handouts / PDF.** A4 question paper with name/date/score fields and instructions; answer key starts on a separate page. Click *Print / Save as PDF* (or Ctrl+P → "Save as PDF"). |
| `TypeScript_Basics_MCQ.md` | **Editing / sharing as text.** Plain Markdown — questions, answer key table, and explanations. Renders on GitHub, Confluence, Notion, etc. |
| `TypeScript_Basics_MCQ.csv` | **Bulk import.** One row per question with columns: No, Section, Question, Option A–D, Correct Answer, Explanation. Load into Excel, Google Forms, Moodle, Quizizz, or any LMS. |

## Question breakdown

**Marks:** 30 (1 each) · **Suggested time:** 30 minutes · **No negative marking**

## Tips

- To print a **student copy without answers**, open the printable HTML, press Ctrl+P and set the
  page range to stop before the Answer Key page (it always begins on a fresh page).
- To open the Markdown or printable HTML in Microsoft Word: right-click → *Open with* → Word,
  then Save As `.docx` if you want to edit it there.
