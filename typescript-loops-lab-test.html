How this works

  • Keep the given function name and parameter order — the grader calls it by name.
  • Return the answer; don't console.log it. Where the original assignment says "print a sequence", return an array instead — the signature on each card tells you exactly what to return.
  • TypeScript annotations are fine — they're stripped before running. Plain JavaScript works too.
  • Infinite loops are caught, not fatal: every loop is instrumented with a guard that aborts after ~2 seconds and reports it as a failed test, so a runaway while won't freeze the page or lose your work.
  • Your code is saved in this browser as you type, so a refresh won't lose it.
  • String answers are compared case-insensitively; arrays must match in order and length.
  • Tick Practice mode to check one assignment at a time instead of waiting for the final submit.
